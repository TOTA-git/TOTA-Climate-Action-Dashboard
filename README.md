# TOTA-Climate-Action-Dashboard

An interactive **R Shiny dashboard hosted by Posit Connect Cloud** that brings together publicly available climate action data for the Thompson Okanagan region.

The dashboard was developed by the **Thompson Okanagan Tourism Association (TOTA)** to support climate action reporting for the **UN Tourism International Network of Sustainable Tourism Observatories (INSTO)**. This dashboard contributes to ongoing efforts to better understand the relationship between climate change and tourism in the Thompson Okanagan Region.

## Dashboard

**Live App:** https://tota2-climate-action-dashboard.share.connect.posit.cloud/

## Features

* Temperature - hot days >= 30 degrees for Kelowna, Kamloops, Penticton, Vernon.
* Wildfires - number of wildfires in the region.
* Drought - current and historic drought levels.
